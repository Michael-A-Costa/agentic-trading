# 10x roadmap — where the leverage actually is (2026-09-25)

Status: **notes, nothing built.** Answer to "how do we 10x this app".

## Reality check
- The sleeve's spendable cash is currently below the price of **one** IBIT share, so it can't trade
  even when armed. Most account equity sits in the owner's manual SATA position (outside the caps).
- `TREND_ARMED=0` — only the shadow ledger trades.
- Best validated edge: BTC 50d trend ≈ **+24%/yr OOS** (`docs/strategy-redesign-2026-09.md`). 10x at
  that rate is ~11 years. Anything faster means leverage or lottery bets. The bake-offs already
  refuted options income, RH crypto, and intraday momentum.

So "10x" can't honestly mean returns. It can mean the four levers below.

## Levers, in priority order
1. **Put money in front of the strategy.** At ~$2.5k the sleeve runs at its intended 2% risk budget
   (~12 IBIT shares, resting GTC stop). Pre-registered gate still applies: ≥20 trading days of clean
   plumbing before arming. Owner decision, not code.
2. **Take it off the laptop.** The launchd jobs (`trend-open`/`-close`/`-status`) fire only while the
   Mac is awake, so a missed 09:45 run means a missed entry or exit. Move them to an always-on host
   or a scheduled cloud agent.
3. **Run several trend sleeves instead of one.** Time-series momentum across asset classes is among the
   best-documented edges. Uncorrelated sleeves lift Sharpe more than tuning one. `trend_sleeve.py` is
   already pure signal/sizing/stop, so it could run on IBIT, SPY/QQQ, GLD, TLT and (small) ETHA with
   portfolio-level exposure caps. **Bake-off first**: params chosen on older data, scored on newer.
   ETH already failed once as fragile OOS.
4. **Test the other surviving edge: PEAD / catalyst drift.** Large caps showed t up to 3.1 at 10–20d
   holds (memory: xsection-momentum-is-survivorship). The MCP now has `get_earnings_calendar`,
   `get_earnings_results` and `get_equity_historicals`, so it can be backtested entirely in code
   with no LLM discretion. It runs on the multi-day horizon where the old engine's signal had edge.

## Not doing

- Leverage
- Reviving intraday / LLM-discretion trading
